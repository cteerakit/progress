Progress for Google Slides

Track slide completion inside Google Slides with status chips on every filmstrip thumbnail and a progress badge in the title bar. Optionally sync statuses with collaborators through Google Drive.

Add to Chrome View on GitHub

Free Chrome extension · Works in Google Slides edit mode

What you get

  • Five status labels: No status, To do, In progress, Need attention, and Done
  • Status chip on each filmstrip thumbnail with a quick picker
  • Title-bar badge with percent complete and per-status counts
  • Optional Google sign-in to sync with collaborators via Drive file metadata
